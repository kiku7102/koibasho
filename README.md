# 恋場所 〜恋の決まり手〜 Prologue v6 — 主人公導入版

オープニングを、剛ノ山の紹介だけではなく「主人公＝あなた」の物語として再構成しました。

## 新しい導入
1. あなたは今日から雷神部屋の広報担当
2. 主人公視点の第一印象「……大きい。少し怖そう」
3. 本場所と相撲の世界
4. 剛ノ山の紹介
5. 「あなたの言葉が、この男の明日を変える」というゲームテーマ
6. タイトル表示
7. 剛ノ山との最初の会話へ接続

主人公の性別・容姿・年齢は固定していません。
プレイヤーが自分を投影できるよう、必要最低限の設定だけを提示しています。

## スキップ
初回は最後まで再生。
一度見終わると、2回目以降は「オープニングをスキップ」が表示されます。

今回オープニング内容を変更したため、既読キーも v2 に更新しています。
既存プレイヤーにも新しいオープニングが一度だけ表示されます。
